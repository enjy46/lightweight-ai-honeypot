# Lightweight AI Honeypot

## Overview
A lightweight AI-powered cybersecurity framework for SMEs combining:
- Random Forest malware detection
- VirusTotal integration
- Honeypot deception services
- Real-time network monitoring

## Features
- SYN flood detection
- ICMP flood detection
- Decoy services (FTP, SSH, HTTP, HTTPS, etc.)
- Malware detection using ML
- VirusTotal API integration
- File monitoring and hashing

## Technologies
- Python
- Scapy
- Watchdog
- pefile
- joblib
- pandas

## Results
- 99.15% accuracy
- 0.9994 AUC-ROC
